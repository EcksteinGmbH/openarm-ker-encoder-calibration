# 标定工位参考链:选型与采购清单

记录日期:2026-09-19,2026-09-20 按精度审核修订,**2026-09-21 改为通轴方案** · 状态:**电机与驱动已下单,待到货安装** · 对应规格:`protocol-spec.md` §7.7 与其中标记为 v6.2 的小节、O3

> **2026-09-21 的变更。** 拓扑从"实心轴参考编码器 + 双出轴步进电机"改为"**两个通轴光栅编码器夹在一根精密光轴上**"。
> 起因是同价位能买到的通轴编码器,纸面精度高约一个数量级。
> 代价是规格 §7.7 的 **A 组换位不能再做**——夹紧式编码器每次重新夹紧都会改变偏心。
> 仿真结论:**只做 B 组**反而更好,且对重新夹紧完全免疫;但第二个编码器从"建议"变成"**必需**"。
> 证据:`evidence/v7-throughbore/`。动手搭建看 `bench-and-station.md` 第二部分。

## 1. 用途与工位拓扑

标定工位用参考编码器提供每个位置的真实角度 `θ_true`(规格 §7.2)。模块本身和装在机械臂上的运行都不需要它。

编码器模块是自带轴承、磁铁嵌在 horn 里的封闭单元(规格 §2.8),它的 horn 无法和转轴刚性连接,所以工位上有**两个**联轴器:

```
步进电机 ── C1 ── [ 一根精密光轴,两个轴承座 ] ── C2 ── 模块的 horn        模块壳体固定在夹具上
                      ↑ 光栅1(核查)   ↑ 光栅2(定义 ψ)
```

三件事跟着这个拓扑走:

- **只有 C2 影响 `θ_true`**。C1 在两个编码器的上游,它的误差永远到不了。预算集中在 C2 上,C1 随便。
- **步进电机不需要双出轴了**,它在链条末端。同时这让它的杂散磁场尽可能远离传感器——电机是永磁体加通电线圈,而传感器测的是磁场方向。
- **两个编码器错开 90° 夹紧**。同型号的细分误差周期相同,装成同相位会让误差在两者比对中抵消,而那个比对是唯一能发现装夹位移的手段。

## 3. 参考编码器

### 选型理由

| 项目 | 选择 | 理由 |
|---|---|---|
| 圈数 | 单圈 | 工位只在 0–360° 内转;多圈需外接 3.6 V 锂电池,没有收益,还多一个故障点 |
| 分辨率 | 23 位或 21 位 | 21 位一格 0.62″,已远小于 ±50″ 的精度;25 位多出的只是噪声位 |
| 协议 | Modbus-RTU | 普通 USB-RS485 转换器加 Python 就能读 |
| 不选 | 2.5M/5M 绝对值伺服(多摩川)、SSI、BiSS-C | 需要专用高速硬件或 MCU |
| 轴型 | **通轴**(2026-09-21 改) | 同价位纸面精度高约一个数量级。规格 §7.7 原本警告不要用通轴/套装式,那条警告针对的是**重复性不是精度**——见下 |

### 通轴的代价:安装误差,以及重新夹紧

通轴编码器没有自己的轴承,转子相对定子的偏心由**你的轴的跳动加上每一次夹紧**决定。偏心 `e` 在光栅半径 `r` 上产生约 `e/r` 的一次谐波误差:

> `e` = 10 µm,`r` = 25 mm → 10 µm / 25 mm = 4×10⁻⁴ rad ≈ **82 角秒**

对比它标称的几角秒刻划精度——**安装引入的误差比器件本身大一个数量级以上**。所以:

1. 规格书上的精度是理想安装下的值。**装完用千分表实测光轴跳动,那个数才是你手上的精度。**
2. 规格 §7.7 的 A 组要求把参考重新夹紧 10 次,而每次重新夹紧都会改变偏心。仿真显示重新夹紧误差到 16″+8″(约 1.9 µm)时,调试判据的通过率只剩 2.5%。**所以 A 组不能做**,改为只做 B 组(§5)。

### 商品页标称参数(未经验证)

| 参数 | 标称值 |
|---|---|
| 绝对精度 | < ±50″(约 ±0.014°) |
| 重复精度 | < ±3″ |
| 波特率 | 默认 9600 bps |
| 供电 / 电流 | 5 V / ≤ 90 mA |
| 最高转速 | ≤ 6000 RPM |
| 工作温度 | −25 ~ +85 °C |
| 防护 | IP40 |

单圈 Modbus-RTU 接线(以外壳标签为准):红 5V+、黑 GND、蓝 RS485A+、蓝黑 RS485B−、粗黑 屏蔽。

### 下单前向卖家确认

1. **±50″ 是否逐台实测?能否附误差曲线或检测报告?是光学还是磁编?** 这一条最重要。磁编不能作为 0.02° 公差的参考:典型的低成本 21 位磁编 IC,用户校准后的线性度指标也只有约 ±250″。
2. **轴的形式:是否实心轴、自带轴承?** 空心轴或分体式编码器的偏心会随每次安装而变,自校准对 1 次谐波就不成立。
3. Modbus 寄存器表:
   - 位置寄存器是否输出完整的 21/23 位单圈值;
   - 读到的是锁存的采样值还是滤波值;
   - 最高波特率;
   - 计数方向能否设置。
4. 轴径,以及允许的轴向和径向负载。
5. 所选组合的价格与货期。

### 到货验收(只用工位软件,不需要额外设备)

1. 读数时拿一块小磁铁靠近外壳。读数有任何变化,就说明是磁编。
2. 静态噪声:在 8 个角度各读 1000 次,看 σ 以及哪些低位在跳动。
3. 多圈重复性:16 个位置 × 10 圈,同方向接近,看 `ψ − θ_s` 的散布是否支持"±3″"。
4. 从反方向接近,再做一遍第 3 项。
5. 细扫:在几度范围内用最小微步走 ≥ 1000 个位置,和模块的读数对比(模块曲线是平滑的)。
   - 周期小于约 10° 的结构属于参考编码器。
   - 由周期可以判断是光学(360°/2ⁿ 线)还是磁极距(11.25° 或 5.6°)。
   - 它的幅值就是细分误差。
6. 在两个位置各记录 30 分钟的预热漂移。

## 4. 精度账

数字来自工位计量审核(`reviews/2026-09-20-accuracy-review-station-metrology.md`)和 v6 仿真(`evidence/v3-reference/results/ref_selfcal.txt`)。

| 方案 | θ_true 的误差 | A 级模块的绝对系统误差(工位条件下) |
|---|---|---|
| 直接使用(±50″),联轴器误差未处理 | 约 65–112″ | 约 0.04–0.05° |
| v5 的自校准(在编码器一侧换位) | 约 50″,**基本没有改善** | 约 0.03–0.045° |
| **v6 调试流程 + 编码器级联轴器** | **约 14–18″**,其中会进入模块系数的 1–6 次谐波部分约 5–10″ | **约 0.025–0.03°** |
| **通轴 + 只做 B 组**(2026-09-21) | **13.4″ 中位 / 17.2″ 最差**,其中 1–6 次谐波 **3.4″ / 6.5″** | 与上一行同量级或略好 |

最后一行来自 `evidence/v7-throughbore/reclamp_sweep.txt`,200 个模拟台架。它比 v6 流程略好,因为 A 组那 21 个额外圈次每一圈都带进一份新的夹紧误差。

**这些只是工位条件下的数字**:单一温度、单一朝向、无负载、周围没有其他模块。装到机械臂后的关节角精度估计为 0.1–0.4°(规格 §7.8),要以整臂多姿态验证的实测结果为准(规格 §9.6)。

在做过一次独立比对之前,上述精度只能表述为"自洽",不能说"可溯源"。独立比对可以是借用一台带校准证书的编码器,也可以送计量机构用多面棱体加自准直仪检定。

## 5. 工位调试(建站时做一次)

需要重做的情况:参考编码器、任一联轴器或夹具被动过之后。完整的规范步骤见规格 §7.7。

1. 选一个模块作为传递件。提前通电 ≥ 30 分钟;全程用 `GET_ENV` 监视温度,变化不超过 ±2 个计数(1 个计数约 0.36 K)。

2. **A 组不做。**(2026-09-21 改。)规格 §7.7 的 A 组把参考编码器重新夹紧 10 个角度,用来把参考自身的误差曲线从模块误差里分离出来。对实心轴编码器这是对的——它的误差是一条被旋转的固定曲线。对**夹在轴上的通轴编码器则不成立**:每一次重新夹紧都改变偏心,"同一条曲线被旋转"这个前提没了。

   *仿真实测*(`evidence/v7-throughbore/reclamp_sweep.txt`,每行 200 个模拟工位):

   | 重新夹紧误差 | ≈ 偏心(r=25 mm) | §7.7 流程通过两条判据 | 只做 B 组 |
   |---|---|---|---|
   | 3″+2″ | 0.4 µm | 100% | 100% |
   | 8″+4″ | 1.0 µm | 93.5% | 100% |
   | 16″+8″ | 1.9 µm | **2.5%** | 100% |
   | ≥ 25″+12″ | ≥ 3 µm | **0%** | 100% |

   **所以:两个编码器夹一次,此后永不重新夹紧。**

3. **B 组,horn 一侧。**这是唯一要做的一组,共 16 圈(8 个角度去程回程各一遍;用 12 个角度略好一点)。
   - 模块壳体固定不动,把 horn 在 C2 里换角度。
   - 要转的是 horn,不是模块壳体:转动壳体会改变环境磁场在传感器坐标系里的方向。
   - 其中一个角度(比如 100°)做**核查**,不参与拟合。
   - 角度不需要准,±3° 即可。

4. 拟合。只做 B 组时 `R′` 和 `S2` **无法分离**,也不需要分离:所有圈次和之后的量产都在同一个装夹上,拟合出来的那一条曲线里已经包含了参考自身的误差、它的夹紧偏心、以及 C2 的平均传动误差。量产时 `θ_true = ψ − R̂′(ψ)`。

   结果:`θ_true` **13.4″ 中位 / 17.2″ 最差**,其中能进入模块系数的 1–6 次谐波部分 **3.4″ / 6.5″**——比 §7.7 的流程略好,因为 A 组那 21 个额外圈次每一圈都带进一份新的夹紧误差。

   **只做 B 组放弃了什么:**它无法察觉参考的装夹**在调试之后**发生位移,因为判据是在位移之前算出来的。

   | 事后位移 | 1–6 次谐波误差 | 重复性 | 核查 | 仍然通过 |
   |---|---|---|---|---|
   | 无 | 3.4″ | 3.3″ | 2.5″ | ✅ |
   | **1.0 µm** | **10.7″** | 3.3″ | 2.5″ | ✅ |
   | 1.9 µm | 20.1″ | 3.3″ | 2.5″ | ✅ |
   | 4.8 µm | 49.5″ | 3.3″ | 2.5″ | ✅ |

   **1 µm 的位移让能进入模块的误差翻三倍,而每一项指标依然全绿。**这就是第二个编码器从"建议"变成"必需"的原因:两个编码器夹在同一根刚性轴上看到同一个机械角度,它们的差值是工位里**唯一**能发现其中一个动了的东西。**每次标定都读两个并记录差值**,和调试时的基准比。
5. **判据**(暂定,见规格 §7.7):
   - 重复性 ≤ 8″(rms),对 B 组各圈次算;
   - 100° 核查装夹的残差,1–7 次谐波的幅值都 ≤ 12″。
   - 仿真中各种工位同时通过两条判据的比例:

     | 工位状况 | 通过率 |
     |---|---|
     | 良好 | 100% |
     | 夹紧误差 10″ | 70% |
     | 夹紧误差 20″ 以上 | 0% |
     | 传递件漂移 2% | 92% |
     | 传递件漂移 5% | 28% |
     | 传递件漂移 10% | 3% |

   - 所有故障等级下,通过两条判据的工位,θ_true 误差最大约 24″,其中 1–6 次谐波部分最大约 15″。
   - 这个结论有两个前提:联轴器 2 是编码器级的;参考编码器的细分误差 ≤ 8″。两条判据都看不出这两点:

     | 情形(仍能通过判据) | θ_true 误差 | 其中 1–6 次谐波部分 |
     |---|---|---|
     | 细分误差 20″ | 31″ | 13″ |
     | 联轴器 2 用波纹管 | 38″ | 32″ |

   - 细分误差靠到货验收里的细扫来测;联轴器类型靠采购时把关。

C2 的误差里**随单元变化的那部分校不掉**:每个模块装进夹具时的对中都不一样。仿真里这部分变化 30% 时:

| C2 的类型 | θ_true 误差(中位 / 最大) | 其中 1–6 次谐波部分 |
|---|---|---|
| 膜片式 | 14.0″ / 17.9″ | 4.7″ / 9.5″ |
| 波纹管 | 23.4″ / 40.2″ | 14.7″ / 31.0″ |

因此 C2 必须是编码器级的,夹具也要能把模块壳体重复地定位。

## 6. 每次测量的要求

- **等转台停稳再读**:
  - 从发 `SAMPLE_START` 之前,到读完 `GET_SAMPLE` 之后,持续轮询参考编码器;θ_true 取这些读数的均值。
  - **这些读数平稳才算数**,否则等待后重测。平稳的标准有两条:标准差不超过到货验收时测得的静态噪声的 2 倍;前半段和后半段的均值相差 ≤ 3″。
  - 只读一次的风险:步进电机停转后还在振荡,如果只等 100 ms 就读一次,误差可达 91″。
- 关闭步进驱动器的"停转自动降电流"功能,或者等它完成后再测。
- 每个位置都要从正转、反转两个方向各接近一次(规格 §7.2)。
- 工位远离钢铁件和步进电机的杂散磁场;记录工位的朝向。
- 三者同轴:编码器、转轴、horn;编码器壳体固定可靠,不能被扭矩带动。
